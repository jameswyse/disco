<h1 align="center">Disco</h1>

<p align="center">
  <strong>Find your next film or series.</strong><br>
  A personal media browser for your Seerr and Plex setup.
</p>

<p align="center">
  <a href="docs/setup.md">Get started</a> ·

![Disco's browse page with saved views, filters, and live film results.](docs/assets/browse.png)

Build a sidebar around your favourite streaming services, studios, genres, and languages.
Your existing [Seerr](https://github.com/seerr-team/seerr) instance handles accounts, metadata,
and requests through to Radarr, Sonarr, and Plex.

Follow the [setup guide](docs/setup.md) to run Disco with Docker Compose or from source.
Maintainers can use the [release guide](docs/releases.md) to publish a version.
