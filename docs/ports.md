# Why port 8785

Port 8785 avoids common media-server defaults. It was unassigned in the
[IANA registry](https://www.iana.org/assignments/service-names-port-numbers/service-names-port-numbers.csv)
when checked on 15/09/2026; it is not reserved for Disco.

Port 8780 was rejected because [Nextcloud HaRP](https://github.com/nextcloud/HaRP) uses it
for its ExApps frontend.
